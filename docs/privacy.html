SharePoint Loader — Privacy Policy

Last updated: 26 July 2026

SharePoint Loader is a browser extension with one purpose: to give you the complete contents of the SharePoint list you are viewing. It can load every item into the page, and it can save the list to a CSV or JSON file on your device.

What is collected

Nothing. The extension does not collect, store, sell, or transmit your personal information. It uses no analytics, advertising, remote code, accounts, or external services, and it sends nothing to the developer or to any third party.

What the extension does

  • To read a list, it calls SharePoint's own API on the site you already have open, using your existing sign-in. These requests go only to that SharePoint site, and they only ever read — the extension never writes to SharePoint.
  • When you choose Load full list, it examines page layout and row markers in order to scroll the list and report progress.
  • All of this happens in your browser. List contents exist only in the open page's memory and are discarded when the page is closed or reloaded.

Permissions

  • Access to SharePoint sites (*.sharepoint.com, *.sharepoint.cn, *.sharepoint.de, *.sharepoint.us) — needed to add the extension's panel to list pages and to read the list you are viewing. Every Microsoft 365 tenant has its own SharePoint subdomain, which is why the match is broad. The extension does not run on any other site.
  • storage — stores your preferences only: items per request, folder crawl limits, CSV delimiter and byte order mark, whether dates are shown in UTC, and the timings used when loading a list by scrolling. Chrome may sync these between your own signed-in Chrome profiles. No list content is stored.

Files you export

Exported files are saved by your browser wherever you choose. They may contain whatever your list contains, including names or email addresses held in that list. The extension keeps no copy of them, and they are never sent anywhere.

Retention and deletion

The extension retains no user data. Uninstalling it removes its code and your stored preferences. Files you have already saved are unaffected and remain yours to delete.

Changes to this policy

If the extension's behaviour changes, this page is updated along with it. The date above reflects the most recent revision, and the full history is public in the source repository.
