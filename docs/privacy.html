SharePoint Loader — Privacy Policy

Last updated: 8 September 2026

SharePoint Loader is a browser extension with one purpose: to give you the complete contents of the SharePoint list you are viewing — loading every item into the page, and finding an item in it by name.

What is collected

Nothing. The extension does not collect, store, sell, or transmit your personal information. It uses no analytics, advertising, remote code, accounts, or external services, and it sends nothing to the developer or to any third party.

What the extension does

  • It asks SharePoint for the list's item count, using SharePoint's own API on the site you already have open and your existing sign-in. These requests go only to that SharePoint site, and they only ever read — the extension never writes to SharePoint.
  • When you type in the find field, it asks the same API for the names of the items in the folder you are viewing, so it can show you the ones that match. The names are kept in the open page only, and are dropped as soon as you move to another folder.
  • When you choose Load full list, it examines page layout and row markers in order to scroll the list and report progress.
  • All of this happens in your browser. List contents exist only in the open page's memory and are discarded when the page is closed or reloaded.

Permissions

  • Access to SharePoint sites (*.sharepoint.com, *.sharepoint.cn, *.sharepoint.de, *.sharepoint.us) — needed to add the extension's panel to list pages and to read the list you are viewing. Every Microsoft 365 tenant has its own SharePoint subdomain, which is why the match is broad. The extension does not run on any other site.
  • storage — stores your preferences only: scrolling timings, theme, and (for a later export option) items per request, folder crawl limits, CSV delimiter and byte order mark, and whether dates are shown in UTC. Chrome may sync these between your own signed-in Chrome profiles. No list content is stored.

Retention and deletion

The extension retains no user data. Uninstalling it removes its code and your stored preferences.

Changes to this policy

If the extension's behaviour changes, this page is updated along with it. The date above reflects the most recent revision, and the full history is public in the source repository.
